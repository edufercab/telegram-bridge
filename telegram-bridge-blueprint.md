## 1. Project Overview

### Vision

Telegram Bridge es un servidor local Node.js que actúa como canal de comunicación bidireccional entre una sesión de Claude Code en el terminal y el usuario vía Telegram. Cuando Claude se "conecta" al bridge, sus respuestas se formatean y se envían al chat de Telegram del usuario; los mensajes que el usuario manda desde Telegram quedan en cola para que Claude los lea y procese. Cuando no hay sesión activa, el bot responde automáticamente "Claude no está disponible ahora."

El sistema es personal y local-first: corre en la misma máquina donde corre Claude Code, sin infraestructura cloud adicional. Claude es consciente del bridge — lo usa activamente como canal de output/input a través de un CLI wrapper y prompts que le explican cuándo y cómo usarlo.

### Goals

- Claude puede enviar mensajes a Telegram desde cualquier sesión de Claude Code con un solo comando
- El usuario puede hablar con Claude desde Telegram y Claude lee esos mensajes en su loop normal
- El usuario puede decirle a Claude "desconéctate" desde Telegram y Claude obedece
- El bot está siempre activo pero permanece silencioso hasta que Claude se conecta explícitamente
- Setup completo en menos de 45 minutos desde cero

### Success Metrics

- Mensaje Claude → Telegram entregado en menos de 2 segundos
- 100% de mensajes Telegram → Claude almacenados sin pérdida mientras la sesión está activa
- Claude responde correctamente a comandos de desconexión enviados desde Telegram
- Un Claude Code frío puede conectarse al bridge solo con leer el CLAUDE.md global

## 4. Data Model

### Entidades

**session** — estado de sesión (singleton: siempre exactamente 1 fila)

| Campo | Tipo | Notas |
|-------|------|-------|
| id | INTEGER | PRIMARY KEY, CHECK (id = 1) — garantiza singleton |
| active | INTEGER | 0 = desconectado, 1 = conectado |
| started_at | TEXT | ISO timestamp, NULL cuando inactive |
| last_activity | TEXT | ISO timestamp, actualizado en cada /send o /inbox |

**inbox_messages** — mensajes del usuario (Telegram → Claude)

| Campo | Tipo | Notas |
|-------|------|-------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT |
| telegram_message_id | INTEGER | ID del mensaje en Telegram (para referencia) |
| from_username | TEXT | Username de Telegram del remitente, nullable |
| message | TEXT | Texto del mensaje |
| created_at | TEXT | ISO timestamp, DEFAULT `datetime('now')` |
| read | INTEGER | 0 = no leído, 1 = leído/procesado por Claude |

### Relationships

Dos tablas independientes. Sin foreign keys. `session` es un singleton. `inbox_messages` es una cola FIFO.

### Database Schema

```sql
CREATE TABLE IF NOT EXISTS session (
  id            INTEGER PRIMARY KEY CHECK (id = 1),
  active        INTEGER NOT NULL DEFAULT 0,
  started_at    TEXT,
  last_activity TEXT
);

INSERT OR IGNORE INTO session (id, active) VALUES (1, 0);

CREATE TABLE IF NOT EXISTS inbox_messages (
  id                  INTEGER PRIMARY KEY AUTOINCREMENT,
  telegram_message_id INTEGER NOT NULL,
  from_username       TEXT,
  message             TEXT    NOT NULL,
  created_at          TEXT    NOT NULL DEFAULT (datetime('now')),
  read                INTEGER NOT NULL DEFAULT 0
);

CREATE INDEX IF NOT EXISTS idx_inbox_read ON inbox_messages(read);
```

## 8. Authentication & Authorization

### Auth Method

API Key simple. Todas las rutas excepto `/health` requieren el header `X-API-Key: <valor>`. El middleware `apiKey.ts` compara contra `process.env.API_KEY`. Retorna 401 si no coincide o está ausente.

### Roles

Un solo actor: Claude. El bot de Telegram no usa API key — está dentro del mismo proceso.

Solo el `TELEGRAM_CHAT_ID` configurado puede enviar mensajes al bot. Si el mensaje viene de otro chat, el bot responde "No autorizado." y no encola nada.

### Session Management

Sin sesiones HTTP. Cada request es stateless con API key en header. El estado de "conectado/desconectado" vive en la tabla `session` de SQLite (singleton).

**Step 4: Formatter — Markdown a Telegram HTML**

Crear `src/lib/formatter.ts`:
```typescript
function escapeHtml(text: string): string {
  return text.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
}

export function markdownToHtml(text: string): string {
  // Preservar bloques de código antes de procesar
  const codeBlocks: string[] = []
  let result = text.replace(/```(\w+)?\n?([\s\S]*?)```/g, (_, _lang, code) => {
    codeBlocks.push(`<pre><code>${escapeHtml(code.trim())}</code></pre>`)
    return `__CODE_BLOCK_${codeBlocks.length - 1}__`
  })

  // Inline code
  const inlineCodes: string[] = []
  result = result.replace(/`([^`]+)`/g, (_, code) => {
    inlineCodes.push(`<code>${escapeHtml(code)}</code>`)
    return `__INLINE_CODE_${inlineCodes.length - 1}__`
  })

  // Escapar HTML en el texto restante
  result = escapeHtml(result)

  // Bold y italic (después de escapar, los marcadores markdown no tienen < > &)
  result = result
    .replace(/\*\*(.+?)\*\*/g, '<b>$1</b>')
    .replace(/__(.+?)__/g, '<b>$1</b>')
    .replace(/\*(.+?)\*/g, '<i>$1</i>')
    .replace(/_(.+?)_/g, '<i>$1</i>')
    // Headings → bold
    .replace(/^#{1,6}\s+(.+)$/gm, '<b>$1</b>')
    // Líneas horizontales
    .replace(/^---+$/gm, '──────────')
    // Múltiples newlines → máximo 2
    .replace(/\n{3,}/g, '\n\n')

  // Restaurar bloques de código
  codeBlocks.forEach((block, i) => { result = result.replace(`__CODE_BLOCK_${i}__`, block) })
  inlineCodes.forEach((code, i) => { result = result.replace(`__INLINE_CODE_${i}__`, code) })

  return result.trim()
}

export function splitMessage(text: string, maxLength = 4000): string[] {
  if (text.length <= maxLength) return [text]

  const chunks: string[] = []
  let remaining = text

  while (remaining.length > maxLength) {
    let splitAt = remaining.lastIndexOf('\n\n', maxLength)
    if (splitAt <= 0) splitAt = remaining.lastIndexOf('\n', maxLength)
    if (splitAt <= 0) splitAt = maxLength

    chunks.push(remaining.slice(0, splitAt).trim())
    remaining = remaining.slice(splitAt).trim()
  }

  if (remaining) chunks.push(remaining)

  // Etiquetar partes si hay más de 2
  if (chunks.length > 2) {
    return chunks.map((chunk, i) => `[${i + 1}/${chunks.length}]\n${chunk}`)
  }
  return chunks
}
```

```typescript
import Database from 'better-sqlite3'
import fs from 'fs'
import path from 'path'

fs.mkdirSync('./data', { recursive: true })
const db = new Database('./data/telegram-bridge.db')

const schema = fs.readFileSync(path.join(__dirname, 'schema.sql'), 'utf8')
db.exec(schema)

// Session
export function getSession() {
  return db.prepare('SELECT * FROM session WHERE id = 1').get() as {
    id: number; active: number; started_at: string | null; last_activity: string | null
  }
}

export function startSession() {
  db.prepare(`UPDATE session SET active = 1, started_at = datetime('now'), last_activity = datetime('now') WHERE id = 1`).run()
}

export function endSession() {
  db.prepare(`UPDATE session SET active = 0, started_at = NULL, last_activity = NULL WHERE id = 1`).run()
}

export function updateSessionActivity() {
  db.prepare(`UPDATE session SET last_activity = datetime('now') WHERE id = 1`).run()
}

// Inbox
export function insertMessage(telegramMessageId: number, fromUsername: string | null, message: string) {
  return db.prepare(
    'INSERT INTO inbox_messages (telegram_message_id, from_username, message) VALUES (?, ?, ?)'
  ).run(telegramMessageId, fromUsername, message)
}

export function getUnreadMessages() {
  return db.prepare('SELECT * FROM inbox_messages WHERE read = 0 ORDER BY created_at ASC').all()
}

export function getAllMessages() {
  return db.prepare('SELECT * FROM inbox_messages ORDER BY created_at ASC').all()
}

export function deleteMessage(id: number): boolean {
  const result = db.prepare('DELETE FROM inbox_messages WHERE id = ?').run(id)
  return result.changes > 0
}
```

**Step 6: Telegram Bot Service**

Crear `src/services/telegram.ts`:
```typescript
import fs from 'fs'
import { Telegraf } from 'telegraf'
import { env } from '../lib/env'
import { TelegramError } from '../lib/errors'
import { markdownToHtml } from '../lib/formatter'
import * as db from '../db'

export const bot = new Telegraf(env.TELEGRAM_BOT_TOKEN)

bot.on('message', async (ctx) => {
  // Solo acepta mensajes del chat configurado
  if (ctx.chat.id !== env.TELEGRAM_CHAT_ID) {
    await ctx.reply('No autorizado.')
    return
  }

  const session = db.getSession()

  if (!session.active) {
    await ctx.reply('Claude no está disponible ahora. 🔴')
    return
  }

  const text = 'text' in ctx.message ? ctx.message.text : null
  if (!text) {
    await ctx.reply('Solo se aceptan mensajes de texto.')
    return
  }

  db.insertMessage(ctx.message.message_id, ctx.from?.username ?? null, text)
  db.updateSessionActivity()
  await ctx.reply('Mensaje recibido ✓')
})

export async function sendMessage(text: string, parseMode: 'HTML' | 'plain' = 'HTML') {
  try {
    const msg = await bot.telegram.sendMessage(
      env.TELEGRAM_CHAT_ID,
      text,
      parseMode === 'HTML' ? { parse_mode: 'HTML' } : {}
    )
    return msg.message_id
  } catch (err: any) {
    throw new TelegramError(`Telegram send failed: ${err.message}`)
  }
}

export async function sendPhoto(source: string, caption?: string): Promise<number> {
  const isUrl = source.startsWith('http://') || source.startsWith('https://')
  const formattedCaption = caption ? markdownToHtml(caption) : undefined

  try {
    const msg = await bot.telegram.sendPhoto(
      env.TELEGRAM_CHAT_ID,
      isUrl ? source : { source: fs.createReadStream(source) },
      formattedCaption ? { caption: formattedCaption, parse_mode: 'HTML' } : {}
    )
    return msg.message_id
  } catch (err: any) {
    throw new TelegramError(`Telegram sendPhoto failed: ${err.message}`)
  }
}

export async function startBot() {
  await bot.launch()
  console.log('✅ Telegram bot activo')
}

export function stopBot() {
  bot.stop()
}
```

```typescript
import { Hono } from 'hono'
import { z } from 'zod'
import { ValidationError } from '../lib/errors'
import { markdownToHtml, splitMessage } from '../lib/formatter'
import { sendMessage } from '../services/telegram'
import * as db from '../db'

const bodySchema = z.object({
  text: z.string().min(1).max(20000),
  format: z.enum(['html', 'plain']).default('html'),
})

export const sendRoute = new Hono().post('/', async (c) => {
  const body = await c.req.json().catch(() => { throw new ValidationError('Body JSON inválido') })
  const parsed = bodySchema.safeParse(body)
  if (!parsed.success) throw new ValidationError(parsed.error.errors[0].message)

  const { text, format } = parsed.data
  const formatted = format === 'html' ? markdownToHtml(text) : text
  const chunks = splitMessage(formatted)

  let lastMessageId = 0
  for (const chunk of chunks) {
    lastMessageId = await sendMessage(chunk, format === 'html' ? 'HTML' : 'plain')
  }

  db.updateSessionActivity()
  return c.json({ success: true, data: { telegram_message_id: lastMessageId, chunks_sent: chunks.length } })
})
```

```typescript
import { Hono } from 'hono'
import { serve } from '@hono/node-server'
import { env } from './lib/env'
import { errorHandler } from './middleware/errorHandler'
import { apiKeyMiddleware } from './middleware/apiKey'
import { healthRoute } from './routes/health'
import { sessionRoute } from './routes/session'
import { sendRoute } from './routes/send'
import { inboxRoute } from './routes/inbox'
import { startBot, stopBot } from './services/telegram'
import * as db from './db'

const app = new Hono()
app.onError(errorHandler)
app.route('/health', healthRoute)

const api = new Hono()
api.use('*', apiKeyMiddleware)
api.route('/session', sessionRoute)
api.route('/send', sendRoute)
api.route('/inbox', inboxRoute)
app.route('/', api)

// Auto-expiración de sesión por inactividad
setInterval(() => {
  const session = db.getSession()
  if (session.active === 0 || !session.last_activity) return

  const minutesIdle = (Date.now() - new Date(session.last_activity).getTime()) / 60000
  if (minutesIdle >= env.SESSION_TIMEOUT_MINUTES) {
    console.log(`⏰ Sesión expirada por inactividad (${env.SESSION_TIMEOUT_MINUTES} min)`)
    db.endSession()
    // Notificar en Telegram sin bloquear
    import('./services/telegram').then(({ sendMessage }) => {
      sendMessage('⏰ Sesión cerrada automáticamente por inactividad.', 'plain').catch(() => {})
    })
  }
}, 60_000)

async function main() {
  await startBot()
  serve({ fetch: app.fetch, port: env.PORT })
  console.log(`🚀 Telegram Bridge en http://localhost:${env.PORT}`)
}

process.once('SIGINT', () => { stopBot(); process.exit(0) })
process.once('SIGTERM', () => { stopBot(); process.exit(0) })

main().catch(console.error)
```

```typescript
#!/usr/bin/env node
import type { InboxMessage, SessionStatus } from './types'

const BASE_URL = process.env.TELEGRAM_BRIDGE_URL ?? 'http://localhost:3001'
const API_KEY  = process.env.TELEGRAM_BRIDGE_API_KEY ?? ''
const headers  = { 'Content-Type': 'application/json', 'X-API-Key': API_KEY }

const [,, command, ...args] = process.argv

async function main() {
  switch (command) {
    case 'status': {
      const res = await fetch(`${BASE_URL}/health`)
      const data = await res.json()
      const { status, uptime, session } = data
      console.log(`Server: ${status} | Uptime: ${uptime}s | Sesión: ${session.active ? '🟢 activa' : '🔴 inactiva'}`)
      if (session.active) console.log(`  Iniciada: ${session.started_at}`)
      break
    }

    case 'connect': {
      const res = await fetch(`${BASE_URL}/session/start`, { method: 'POST', headers })
      const data = await res.json()
      if (!data.success) { console.error(`❌ ${data.error.message}`); process.exit(1) }
      console.log(`✅ Sesión iniciada: ${data.data.started_at}`)
      break
    }

    case 'send': {
      const text = args.join(' ')
      if (!text) { console.error('Uso: cli.js send "texto del mensaje"'); process.exit(1) }
      const res = await fetch(`${BASE_URL}/send`, {
        method: 'POST', headers, body: JSON.stringify({ text })
      })
      const data = await res.json()
      if (!data.success) { console.error(`❌ ${data.error.message}`); process.exit(1) }
      console.log(`✅ Enviado (msg_id: ${data.data.telegram_message_id}, partes: ${data.data.chunks_sent})`)
      break
    }

    case 'inbox': {
      const res = await fetch(`${BASE_URL}/inbox`, { headers })
      const data = await res.json()
      if (!data.success) { console.error(`❌ ${data.error.message}`); process.exit(1) }
      const messages: InboxMessage[] = data.data
      if (messages.length === 0) {
        console.log('📭 Inbox vacío')
      } else {
        console.log(JSON.stringify(messages, null, 2))
      }
      break
    }

    case 'read': {
      const id = args[0]
      if (!id) { console.error('Uso: cli.js read <id>'); process.exit(1) }
      const res = await fetch(`${BASE_URL}/inbox/${id}`, { method: 'DELETE', headers })
      const data = await res.json()
      if (!data.success) { console.error(`❌ ${data.error.message}`); process.exit(1) }
      console.log(`✅ Mensaje ${id} marcado como leído`)
      break
    }

    case 'send-photo': {
      const source = args[0]
      const caption = args.slice(1).join(' ') || undefined
      if (!source) { console.error('Uso: cli.js send-photo <ruta-o-url> ["caption opcional"]'); process.exit(1) }
      const res = await fetch(`${BASE_URL}/send-photo`, {
        method: 'POST', headers, body: JSON.stringify({ source, caption })
      })
      const data = await res.json()
      if (!data.success) { console.error(`❌ ${data.error.message}`); process.exit(1) }
      console.log(`✅ Imagen enviada (msg_id: ${data.data.telegram_message_id})`)
      break
    }

    case 'disconnect': {
      const res = await fetch(`${BASE_URL}/session/end`, { method: 'POST', headers })
      const data = await res.json()
      if (!data.success) { console.error(`❌ ${data.error.message}`); process.exit(1) }
      console.log('🔴 Sesión cerrada')
      break
    }

    default:
      console.log('Comandos disponibles:')
      console.log('  status                          — Estado del servidor y sesión')
      console.log('  connect                         — Inicia sesión (activa el bot)')
      console.log('  send "texto"                    — Envía mensaje de texto a Telegram')
      console.log('  send-photo <ruta|url> ["cap"]   — Envía imagen a Telegram')
      console.log('  inbox                           — Lee mensajes pendientes (JSON)')
      console.log('  read <id>                       — Marca mensaje como leído')
      console.log('  disconnect                      — Cierra la sesión')
      process.exit(1)
  }
}

main().catch(err => { console.error(`❌ ${err.message}`); process.exit(1) })
```

```markdown
# Telegram Bridge

Servidor local Node.js + Telegraf que conecta Claude Code con Telegram de forma bidireccional. Claude se conecta explícitamente cuando el usuario lo solicita; el bot responde "Claude no está disponible ahora" cuando no hay sesión activa.

Hono + @hono/node-server + Node.js 20 + TypeScript + Telegraf v4 + SQLite (better-sqlite3) + Zod

## Architecture

### Directory Structure
- `src/routes/` — health.ts, session.ts, send.ts, sendPhoto.ts, inbox.ts
- `src/services/telegram.ts` — Instancia Telegraf, sendMessage(), sendPhoto(), handlers del bot
- `src/db/` — SQLite (better-sqlite3), session singleton + inbox FIFO
- `src/middleware/` — apiKey.ts (auth) y errorHandler.ts (errores globales)
- `src/lib/` — env.ts (Zod startup validation), errors.ts, formatter.ts (markdown→HTML)

### Data Flow
- Claude→Telegram: bash `cli.js send "texto"` → POST /send → formatter → Telegraf → usuario
- Telegram→Claude: usuario escribe → bot handler → SQLite inbox → bash `cli.js inbox` → Claude procesa

### Key Patterns
- Session es un singleton en SQLite (siempre exactamente 1 fila, id=1)
- El bot usa long-polling (no webhooks) — no necesita tunnel HTTPS ni dominio
- El formatter convierte markdown → HTML de Telegram antes de enviar (parse_mode: HTML)
- Auto-expiración de sesión por inactividad via setInterval en index.ts
- Puerto 3001 por defecto (3000 reservado para alexa-bridge si coexisten)

| `API_KEY` | Clave secreta (≥16 chars) para autenticar llamadas al API |
| `TELEGRAM_BOT_TOKEN` | Token del bot (BotFather) |
| `TELEGRAM_CHAT_ID` | Chat ID numérico del usuario autorizado |
```

## 16. Reglas No Negociables

1. **Nunca commitear credenciales.** `.env` y `data/` siempre en `.gitignore`.
2. **Shape de respuesta consistente.** Siempre `{ success: boolean, data?, error? }`. Sin excepciones en ninguna ruta.
3. **Solo el TELEGRAM_CHAT_ID autorizado.** El bot rechaza cualquier mensaje de un chat distinto. Sin excepciones.
4. **Telegraf en try/catch.** La API de Telegram puede fallar; el servidor no debe crashear — capturar error, retornar 503, loguear.
5. **Formatter escapa antes de pasar a Telegram HTML.** `<`, `>`, `&` en texto libre siempre escapados. Nunca pasar HTML sin sanitizar.
6. **`data/` se crea al startup.** `fs.mkdirSync('./data', { recursive: true })` en `src/db/index.ts`. No asumir que existe.
7. **Sin webhooks.** El bot usa long-polling (Telegraf por defecto). No configurar webhooks — no hay servidor público.
8. **El CLI es el contrato con Claude.** No cambiar los nombres de comandos (`connect`, `send`, `inbox`, `read`, `disconnect`, `status`) sin actualizar también los prompts.
